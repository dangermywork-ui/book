## Использование SSHFS-Win (Продвинутый вариант, интеграция в систему)

Если ты предпочитаешь решения с открытым исходным кодом (Open Source) и хочешь, чтобы диск монтировался моими собственными, "родными" средствами без постоянно висящей в трее программы, этот способ для тебя.

Для этого нам понадобятся два компонента: **WinFsp** (драйвер пользовательских файловых систем для Windows) и сама утилита **SSHFS-Win**.

1. Зайди на GitHub и скачай/установи последние релизы **WinFsp** и **SSHFS-Win** (устанавливать нужно именно в таком порядке).
2. После установки никаких новых программ запускать не нужно. Открой мой Проводник и нажми **Этот компьютер**.
3. В верхней панели выбери **Подключить сетевой диск** (Map network drive).
4. Выбери любую свободную букву диска.
5. В поле **Папка** (Folder) введи специальный путь в следующем формате:
* `\\sshfs\ТвойЛогин@IP_Адрес_Сервера`
* *Пример:* `\\sshfs\root@192.168.1.50`


6. Нажми **Готово**.
7. Я выведу стандартное окно безопасности Windows с просьбой ввести пароль от сервера. Введи его и поставь галочку «Запомнить учетные данные».

Диск будет успешно подключен прямо через мой стандартный интерфейс!
