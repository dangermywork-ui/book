## Выгружать (экспортировать) из MikroTik только **активные** правила, исключая отключенные, вам нужно добавить дополнительное условие фильтрации в команду.

## Проброс портов, работающие правила:

```text
/ip firewall nat export where chain=dstnat and disabled=no
```

## Проброс портов

```text
/ip firewall nat export where chain=dstnat
```

## Добавление 
`and disabled=no` - говорит роутеру проигнорировать все выключенные правила при формировании скрипта выгрузки.
